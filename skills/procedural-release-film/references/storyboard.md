# Storyboarding 30 seconds on a beat grid

128 BPM × 64 beats = 30.0 s. 15 s = 32 beats. Write the board as a table before any code.

| Beats | Job | Music |
|---|---|---|
| 0–4 | **Cold open.** A world, a mood, one image. The genre you borrow is set here (VCR blue screen, a film leader, a monolith). | Intro, sparse, a chord that tells the key. |
| 4–16 | **The promise.** The product does its thing at full scale. 3 short captions, one per 2–4 beats. | Drop on beat 8 or 16. |
| 16–24 | **The instrument.** The real UI, hit by the real music: pads flash on the logged hits. | Groove. |
| 24–40 | **The range.** A feature per beat (effects, sounds, presets). Fast cuts justify themselves only if each cut lands on a hit. | The hook. |
| 40–52 | **The trick.** The one thing no competitor does, shown, not said. | Build, fill. |
| 52–64 | **Title.** Name, one-line promise, platforms, store. Hold the last frame ≥ 1.5 s. | Final hit, tail. |

Rules of thumb
- One idea per caption, ≤ 4 words, uppercase if the genre allows.
- A caption starts on a downbeat and ends half a beat before the next one starts.
- If a scene can't react to the music, it's too long.
- Borrow a genre (70s mysticism, 80s VHS, 2001 minimalism) — it gives you fonts, colour and pacing for free. Use OFL fonts that evoke it; never copy a real film's titles or logos.
- 9:16 is not a crop. Stack text, scale the hero up, move UI to the lower third.
